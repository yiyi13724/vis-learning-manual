# 可视化导论 · 交互学习手册

五章、27 个小节，覆盖数据、可视化流程、色彩、低维数据与时序数据。保留原讲义与示例，提供对照学习、自测、笔记、书签和复习工具。纯静态站点，无视频、账号或数据库。

## 发布地址与来源

- 公开访问：https://yiyi13724.github.io/vis-learning-manual/
- 源码仓库：https://github.com/yiyi13724/vis-learning-manual
- 原课程项目：https://github.com/cinger007/vis 。保留原课程作者与教材信息，本仓库为独立重构版本。

## 本地运行

在仓库根目录运行：

```sh
python -m http.server 8080
```

打开 http://localhost:8080/ 。请通过 HTTP 访问；直接双击 HTML 会影响 ES modules、目录索引和数据加载。

## 入口

| 地址 | 内容 |
|---|---|
| `/` | 学习路线、继续学习、章节进度与书签 |
| `lesson-01/` 至 `lesson-05/` | 课程讲解、代码、按需演示、自测与笔记 |
| `lab/` | 五个分主题交互实验 |
| `choose/` | 七类任务的图表选型助手 |
| `supplementary/` | 可筛选的案例库与观察任务 |
| `review/` | 错题、间隔回顾、笔记汇总与备份恢复 |

## 发布与维护

可部署到 GitHub Pages 等静态托管服务，不需要构建命令。保留所有文件的相对路径，尤其是 `assets/` 和各章 `data/`。原 `lesson-01/` 至 `lesson-05/` 地址保持有效。

共用界面与功能位于 `assets/`。五章和补充案例共用本地 D3 7.9.0，许可见 `assets/vendor/LICENSE`；部分历史独立 demo 目录仍使用 CDN。课程目录、搜索正文索引、自测题与目标位于 `assets/catalog.json`，正文变更后需要同步搜索索引。

学习记录仅保存在当前浏览器。请通过复习中心导出 JSON 备份；笔记可单独导出 Markdown。没有远程同步或自动通知。

完整修改与验证范围见 [重构说明](重构说明.md)，设计来源见 [优化依据与功能说明](优化依据与功能说明.md)。
